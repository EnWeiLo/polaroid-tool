# 拍立得小房間

獨立的拍立得邊框小工具。瀏覽器直接開就能用，不必安裝、不必建置。

## 上傳 GitHub Pages

保留這個資料夾的相對路徑，至少要有：

- `index.html`
- `manifest.webmanifest`、`sw.js`
- `icon-192.png`、`icon-512.png`、`icon-512-maskable.png`、`apple-touch-icon.png`
- `fonts/`、`vendor/`

把整個資料夾內容放到 Pages 來源（repo 根目錄或 `docs/`）。

本機預覽：

```bash
npx --yes serve .
```

也可以直接用瀏覽器開 `index.html`（`file://` 可用；Service Worker 只在 HTTP 下會註冊）。

## 功能

- 一次最多 20 張
- 邊框：白框、黑框、取色、復古、底片
- 比例：原圖、方框、Wide、橫幅、Instagram 貼文、限時動態（兩排各三個選項）
- 拖曳裁切，雙指或滾輪縮放
- EXIF 自動帶入相機資料（不改寫原檔）
- 單張下載／分享，多張打包 ZIP

## 主題

右上角可切換：晨光、粉霧、海霧、夜光、全黑。沒有已儲存設定時預設全黑；舊主題會對應至新主題。手機不使用背景模糊或動態光暈。

## 編輯介面與照片處理

- 照片操作區不受分頁切換影響；桌面版左側預覽、右側最上方為照片操作區，下方為版型／文字／日期設定分頁；手機版維持預覽在上、設定在下；照片與預覽隨頁面正常捲動，不受設定分頁切換影響。分享與下載列保持容易取得。
- 第一張照片不顯示同步設定來源；其他照片選擇同步來源後立即套用，完成後持續顯示來源縮圖與檔名，來源刪除時清除關聯。同步目前照片的全部編輯設定，包括邊框、比例、資訊來源模式、手動內容及日期；保留目標照片原圖、EXIF 與裁切。自動資訊使用目標自身資料，手動日期只在使用者編輯日期後同步。
- 原圖完整保留供裁切與匯出；縮圖獨立產生，切換照片不重建已載入的縮圖。
- 多張匯入時，第一張完成後即可預覽，其餘照片逐張加入並顯示進度。
- 桌面保留一般／全螢幕預覽與 Esc 返回；手機保留原有手勢及橫幅預覽規則。

## 合併回歸驗證

`qa/verify-merge.cjs` 使用 Playwright 與已安裝的 Edge，參數依序為輸出資料夾、可選的修改前專案資料夾。測試產物應存放在專案外。這些套件只供 QA 使用，網站執行不需要安裝。

本次僅更新網頁版；Windows WebView2 版本需另行同步與驗證。

- 縮圖使用單排橫向捲動，左右按鈕在端點停用；選取照片時自動顯示其縮圖。
- Instagram 限時動態維持 1080 × 1920，依照片原始比例完整容納；預設不自動裁切，並支援手動拖曳與縮放調整構圖。切換文字、日期或邊框設定不會重設裁切。
- 本輪驗證：qa/verify-sync-story.cjs（同步、縮圖、桌面手機配置、四邊完整性及其他比例輸出比對），qa/verify-layout.cjs（分頁狀態、全螢幕與單張／批次匯出）。
